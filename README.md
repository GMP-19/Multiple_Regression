# Multiple Linear Regression

## Overview

This project explores **Multiple Linear Regression**, a supervised machine learning algorithm that predicts a numerical target using two or more independent variables.

Unlike Simple Linear Regression, which uses one input feature, Multiple Linear Regression considers several features to model their combined relationship with the target variable.

## Objectives

- Understand regression with multiple independent variables.
- Explore relationships between input features and a numerical target.
- Train a Multiple Linear Regression model.
- Generate predictions using multiple features.
- Evaluate prediction accuracy using regression metrics.

## Algorithm

The Multiple Linear Regression model can be represented as:

\[
y = b_0 + b_1x_1 + b_2x_2 + \cdots + b_nx_n
\]

Where:

- `y` is the predicted target value.
- `b₀` is the intercept.
- `x₁, x₂, …, xₙ` are independent variables.
- `b₁, b₂, …, bₙ` are the learned coefficients.

## Workflow

1. Load and explore the dataset.
2. Identify the target variable and independent features.
3. Handle missing values and prepare the data as needed.
4. Split the data into training and testing sets.
5. Train a Multiple Linear Regression model.
6. Generate predictions on test data.
7. Evaluate the model using appropriate regression metrics.
8. Interpret the model coefficients where appropriate.
